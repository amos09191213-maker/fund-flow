# 資金流向 Dashboard · 台股 / 美股 / BTC

手機優先的網頁儀表板，一頁追蹤三個市場的資金流向，並依規則自動產生「訊號 + 理由」。
所有資料皆來自免金鑰的公開 API。

| 分頁 | 看什麼 | 資料來源 |
| --- | --- | --- |
| **台股** | 三大法人（外資/投信/自營商）買賣超、個股排行、雙主力同買、連續買賣超 | 證交所 `T86` / `BFI82U` / `STOCK_DAY_ALL` |
| **美股** | 三大指數 + VIX、11 大類股 ETF 相對 SPY 的資金輪動、大盤訊號 | Yahoo Finance chart API |
| **BTC** | 即時價、24h 高低量、市值、多週期（15m/1h/4h/日）走勢訊號 | Binance ticker/klines、CoinGecko 市值 |

> ⚠️ 所有訊號為程式依規則自動產生，**不構成投資建議**；請自行判斷並承擔風險。

---

## 功能

**台股（資金流向重點）**
- 今日大盤三大法人買賣超（億元）＋ 連續買賣超天數
- 大盤訊號燈（強力偏多～強力偏空），逐條列出判斷理由
- 外資 / 投信近期買賣超趨勢圖（自繪 SVG）
- 個股買賣超金額排行：外資 / 投信 / 合計的買超賣超、雙主力同買
- 重點觀察清單：每檔附訊號標籤 + 理由，可篩偏多 / 偏空 / 分歧

**美股（大盤＋類股資金輪動）**
- S&P 500 / 那斯達克 / 道瓊 / VIX 的價格、日漲跌、5 日報酬、是否站上 20 日均線
- 11 大 SPDR 類股 ETF 相對 SPY 的強弱條狀圖 → 看資金輪動到哪個族群
- 資金流入 / 流出族群、完整類股明細表
- 大盤訊號（指數趨勢 + 類股廣度 + VIX）＋ 理由

**BTC（多週期走勢訊號）**
- 即時價、24h 漲跌 / 高 / 低 / 成交額、市值
- 15 分 / 1 小時 / 4 小時 / 日線的趨勢（快慢均線 7/25）與距均線動能
- 依週期權重加權的綜合多空研判 ＋ 各週期理由

**手機優先**：三市場以上方分頁切換、各分頁按需載入；版面 RWD（手機 2 欄、桌面 4 欄），
表格可橫向捲動，觸控目標夠大。手機與電腦同一個網址即可看。

**進階（部署後可選用，見 [DEPLOY.md](DEPLOY.md)）**
- **美股自訂個股**：美股分頁可輸入任意代號（如 NVDA），存在瀏覽器、免重部署，附價格與多空訊號。
- **Discord / Telegram 推播**：設定 Webhook(或 Bot)後，由 GitHub Actions 在台股/美股盤後定時推送三市場摘要。
- **保持喚醒**：GitHub Actions 每 10 分鐘 ping `/healthz`，避免 Render 免費方案休眠。

## 安裝與啟動

需求：Python 3.8+（開發於 3.10）。唯一外部套件為 `requests`。

```powershell
pip install -r requirements.txt
python server.py            # 自動開瀏覽器 http://127.0.0.1:8787/
```

Windows 可直接雙擊 **`run.bat`**。常用參數：

```powershell
python server.py --port 9000     # 換埠號
python server.py --no-browser    # 不自動開瀏覽器
```
> 台股觀察天數在頁面右上角「觀察天數」即可調整（不需重啟）。

**部署成公開網站**：見 [DEPLOY.md](DEPLOY.md)（Render 免費方案，含密碼保護，已備好設定檔）。

### 用手機看
手機與電腦在**同一個 Wi-Fi** 下，用電腦區網 IP 開啟即可：

```powershell
# 1) 讓伺服器接受區網連線
python server.py --host 0.0.0.0 --port 8787
# 2) 查電腦 IP（例如 192.168.1.20）
ipconfig
# 3) 手機瀏覽器開： http://192.168.1.20:8787/
```
> 若連不到，請在 Windows 防火牆放行該埠，或對 python.exe 允許私人網路。

## API 端點

| 路徑 | 說明 |
| --- | --- |
| `GET /api/tw?days=6&refresh=0` | 台股報告（`/api/data` 為相容舊路徑） |
| `GET /api/us?refresh=0` | 美股報告 |
| `GET /api/btc?refresh=0` | BTC 報告 |
| `GET /api/quote?symbols=NVDA,AAPL` | 美股自訂個股報價＋訊號 |
| `GET /api/push?key=CRON_KEY` | 觸發 Telegram 推播（免密碼、需金鑰，供排程呼叫） |
| `GET /healthz` | 健康檢查（免密碼，供保持喚醒） |

`refresh=1` 會清快取重新抓取。各市場有記憶體快取：台股 10 分、美股 5 分、BTC 45 秒。

## 訊號邏輯（透明、可解釋）

- **台股**：外資權重最高（±2）、投信次之（±1.5）、自營商最低（±0.5），加上連續買賣超天數，
  與內外資分歧提醒。總分對應強力偏多～強力偏空。
- **美股**：S&P 是否站上 20 日均線（±1）、近 5 日報酬（±1）、類股廣度（±1）、VIX 高低（+1～−2）。
- **BTC**：各週期快慢均線（7/25）判多空，依權重 日線 3 / 4h 2 / 1h 1.5 / 15m 1 加權；
  「強力」需含日線在內的多週期一致才成立。

門檻都集中在各 `*.py` 的 `_market_signal()` / `build_*` 函式，要調整很容易。

## 檔案結構

```
tw_fund_flow/
├─ twse.py          # 證交所資料抓取、交易日偵測、磁碟快取
├─ analyze.py       # 台股分析與訊號
├─ usstock.py       # 美股指數 / 類股輪動 / 訊號（Yahoo）
├─ crypto.py        # BTC 多週期訊號（Binance / CoinGecko）
├─ server.py        # http.server + /api/tw、/api/us、/api/btc
├─ index.html       # 手機優先單檔前端（內嵌 CSS/JS）
├─ run.bat          # Windows 一鍵啟動
├─ requirements.txt
└─ cache/           # 台股各交易日資料快取（自動產生）
```

## 已知限制與後續可擴充

- 台股僅含**上市（TWSE）**；上櫃（TPEX）可日後加入。
- 個股「買賣超金額」以「股數 × 收盤價」估算；排行僅含普通股（已排除 ETF/權證/特別股）。
- 美股為延遲報價；無免費的「三大法人」資料，故以類股相對強弱表達資金輪動。
- BTC 走勢依賴 Binance，少數網路環境可能受限。
- 可延伸：台股類股輪動、融資融券、美股自訂個股清單、加密主流幣、Email/Telegram 定時推播。
